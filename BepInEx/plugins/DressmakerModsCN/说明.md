# Dressmaker Mods 汉化插件（Dressmaker Mods Chinese）

本插件把《针影裁梦》里 **Mod Loader 的界面**（模组设置 / 模组管理器 / 各种提示与对话框）在运行时替换为简体中文。
它不修改任何游戏原文件，也不修改 `DressmakerMods.dll` 本身，因此可以随时删除、随时更新。

## 安装位置

```
D:\Dressmaker\BepInEx\plugins\DressmakerModsCN\
    DressmakerModsCN.dll     汉化插件本体
    zh-cn.txt                词条文件（英文 → 中文），可自行修改/补充
    untranslated.txt         运行后自动生成：记录界面上出现但还没有译文的英文
    说明.md                  本文件
```

## 怎么用

1. 正常启动游戏（`D:\Dressmaker\Dressmaker.exe`）。
2. 进入 **暂停菜单 / 选项** → 里面的 **模组设置（Mod Settings）** 与 **模组管理器（Mod Manager）** 界面即为中文。
3. 启动时 `BepInEx\LogOutput.log` 会出现：
   `[Info :Dressmaker Mods Chinese] 汉化插件已加载：N 条译词，... 补丁 4 个。`

## 有没有漏翻的地方？

- 游戏里每 30 秒会把"界面上出现过的英文"写进 `untranslated.txt`（次数 + 文本），退出游戏时也会写一次。
- 把里面想翻的条目按 `英文<TAB>中文` 追加到 `zh-cn.txt` 末尾，**重启游戏**即可生效（不需要重新编译）。
- 词条支持四种写法：

```
普通词条        英文原文<TAB>中文
prefix:前缀     以该前缀开头的整句会被替换（用于 "Could not load xxx: " 这类拼接消息）
suffix:后缀     以该后缀结尾的整句会被替换
regex:^Page (\d+)$<TAB>第 $1 页      正则替换，$1 为捕获组
```

- 行首 `#` 是注释；`\n` 表示换行。文件必须保存为 **UTF-8**。

## 配置项

`D:\Dressmaker\BepInEx\config\cn.dressmaker.modmenu.cn.cfg`

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| RecordUntranslated | true | 记录未翻译文本到 untranslated.txt |
| AddChineseFontFallback | true | 当某个界面字体缺少中文字形时，自动挂载游戏自带的中文字体（SourceHanSansSC）作为回退，避免方块字 |

## v1.0 正式发布包新增内容

本插件现在与图形化工具**汉化助手**（`<游戏目录>\汉化助手\汉化助手.exe`）配套使用：

- `ui-zh.tsv`：由汉化助手维护的"英文 → 中文"名称表（模组名、内容名等），插件启动时加载，
  优先级高于内置词典，可覆盖任何显示文本；
- `content-zh.tsv` / `zh-cn.txt` / `tokens.tsv`：与之前相同，由汉化助手统一读写；
- 插件本身无界面，所有扫描/翻译/编辑都在汉化助手里完成，改完保存后重启游戏生效。

## 卸载

删除 `D:\Dressmaker\BepInEx\plugins\DressmakerModsCN` 整个文件夹即可，游戏回到英文原状。

## v2.0 新增：mod 内容名（布料/配饰/服装部件）汉化

游戏里所有内容名最终都调用 `LocalizedContent.Get("Content", 键, 英文默认值)`，键的规则是
`Fabric/<modID>.<本地ID>/Name`（还有 `Accessory/`、`ItemTag/`、`Bodice|Skirt|Sleeve|Collar/`、`FabricType/`、`Quest/`、`Character/` 等前缀）。
本插件由此做三件事：

1. **给 `LocalizedContent.Get` 打后置补丁**：键命中 `content-zh.tsv` 就返回中文 —— 商店、设计簿、标签、筛选、拼接文本全部同步生效；
2. **把译文写进当前语言的 `Content` 表**（`StringTable.AddEntry`），让游戏自身数据也是中文；
3. **导出待翻译清单** `content-pending.tsv`：游戏里存在、但还没有译文的 mod 内容（键 / 英文名 / 类型）。

### 以后新装 mod 怎么汉化（三步）

1. 把新 mod 放进 `Mods`，启动游戏一次（进到主界面即可），退出；
2. 打开 `BepInEx\plugins\DressmakerModsCN\content-pending.tsv`，里面就是新 mod 的全部内容键与英文名；
3. 把中文按 `键<TAB>中文` 追加到 `content-zh.tsv`（可直接覆盖原行），**重启游戏**即生效。

> 也可以把 `content-pending.tsv` 发给我来翻译，我再写回 `content-zh.tsv`。
> 插件只在中文学界面（locale 以 `zh` 开头）时替换；mod 作者自己提供的中文（表里已有词条）会被尊重、不覆盖。

### 配置文件

`content-zh.tsv`：`本地化键<TAB>中文`，行首 `#` 为注释。键由游戏运行时导出，**不要改动键本身**。

### v2.1 补充

- **覆盖范围扩大到游戏本体**：有些游戏自带布料/标签在官方中文里是缺失的（商店里显示英文），现在也会被导出并翻译（当前 435 条内容名已全部注入）。
- `tokens.tsv`：词元表（英文<TAB>中文）。用于 `<服装名> <部件> <序号>` 这类**生成式名称**，例如
  `Split Skirt SkirtRight 17` → 「开衩裙摆 右裙片 17」、`Ruffle Bodice BodiceBack, BodiceLeft 7` → 「一字领秋海棠衣身 后衣片、左衣片 7」。
  表格来自游戏官方中文（服装/部件名），新服装出现时一般无需改动。
- Mod 管理器里的包名、作者行、提示也纳入界面词典，例如
  `Alice in Wonderland 1`→爱丽丝梦游仙境 1、`v1.0.0 · by Potato Pot`→`v1.0.0 · 作者：Potato Pot`、`Loading problems (6)`→`加载问题（6）`、`Modded 1`→`模组 1`。
- `untranslated.txt` 改为**每次运行都重写**（只反映最近一次运行），避免看到过期内容；里面若还有条目，直接补进 `zh-cn.txt` 即可。
- 启动日志会打印「分词自检」与「内容汉化自检」，可直接确认是否生效。

## 技术说明

- 基于 BepInEx 5 + Harmony，对 `TMPro.TMP_Text.set_text`、`TMP_Text.SetText(string)`、`TMP_Text.SetText(string,bool)`、`UnityEngine.UI.Text.set_text` 做后置补丁。
- 只在文本**完全匹配**词典（或命中 prefix/suffix/regex 规则）时替换，未命中的文本原样不动，因此不会影响游戏本体文本。
- 递归保护：替换时置忙标志，避免 set 回调造成无限递归。
